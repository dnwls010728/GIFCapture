<h1 align="center">GIF Capture</h1>

<p align="center">
  화면의 원하는 부분을 녹화하고, 다듬고, 작은 GIF로 저장합니다. 모든 작업은 내 PC 안에서만 이뤄집니다.<br>
  <a href="README.md">English</a> · <b>한국어</b> · <a href="README.ja.md">日本語</a>
</p>

<p align="center">
  <img src="docs/images/demo.gif" alt="GIF Capture로 녹화하고 자막을 넣은 GIF" width="640">
</p>

GIF Capture는 화면을 녹화해 GIF로 만드는 가벼운 Windows 프로그램입니다. 동료에게 버그를 보여줄 때, 문서에 넣을 짧은
사용법을 만들 때, 게임 장면을 공유할 때처럼 일상적인 상황에 맞춰 만들었습니다. 영역을 고르고 **F9**, 다시 **F9**를 누르면
GIF가 완성됩니다. 필요하면 편집기에서 자르고, 텍스트를 넣고, 용량을 줄인 뒤 저장할 수 있습니다.

계정도, 업로드도, 클라우드도 없습니다. 녹화한 화면과 GIF는 이 PC에만 저장됩니다.

## 다운로드

**[⬇ GifCapture.exe 내려받기 (최신 버전)](https://github.com/dnwls010728/GIFCapture/releases/latest/download/GifCapture.exe)**

Windows 10 2004 이상 / Windows 11(64비트)용 단일 실행 파일입니다. 설치나 .NET 설치 없이 바로 실행하면 됩니다.
처음 실행할 때 Windows SmartScreen 경고가 나오면 **추가 정보 → 실행**을 누르세요.
모든 버전은 [Releases](https://github.com/dnwls010728/GIFCapture/releases) 페이지에 있습니다.

## 기능

**녹화**
- 녹화 대상 선택 세 가지: **영역**을 드래그, **창**을 클릭(창을 옮기면 영역도 따라감), **모니터** 전체
- 화면에 파란 테두리가 계속 보이고, 드래그로 위치와 크기를 조절합니다. 돋보기와 가장자리 스냅으로 픽셀 단위까지 맞출 수 있습니다
- 너비·높이 직접 입력, **크기 프리셋**(360p, 720p, 1080p, 정사각형, 세로형 등)과 내 프리셋 저장
- 1–60 FPS, 마우스 커서 표시, 설명용 **클릭 강조**와 **키 입력 표시**
- 3초 카운트다운, 전역 단축키 **F9**. 앱 자신의 창은 녹화에 찍히지 않습니다

**편집**
- 썸네일 타임라인, 재생, 여러 프레임 선택(Shift / Ctrl / 드래그)
- 삭제, 선택만 남기기, **앞뒤 잘라내기**, 복제, 역재생, 왕복 재생
- 프레임별 표시 시간, 2배 빠르게 / 느리게
- 자르기, 90° 회전, 좌우 반전 (자막은 꾸미기 탭의 텍스트로 넣습니다)
- 미리보기 확대·이동, 모든 작업 실행 취소 / 다시 실행

**꾸미기**
- 모든 프레임에 **워터마크**: 글자(설치된 모든 글꼴과 스타일, 색, 크기, 투명도, 가독성을 위한 어두운 외곽선 선택) 또는 투명 PNG 로고 같은 이미지
- 9방향 위치 격자로 배치하거나, 미리보기에서 끌어 옮기고 모서리 핸들로 크기를 조절
- 워터마크 설정은 다음에도 기억되고 **바로 저장**에도 적용됩니다
- 원하는 프레임에 **이미지(스티커) 넣기**: 타임라인에서 고른 프레임에 버튼, **Ctrl+V** 붙여넣기, 또는 이미지 파일을 미리보기로 끌어다 놓아 추가. 미리보기에서 끌어 이동·크기 조절, 이미지별 투명도, 선택한 프레임에 더 표시 / 선택한 프레임에서 제거, **Del**로 삭제
- 넣은 이미지는 **회전**할 수 있습니다: 미리보기에서 선택한 이미지 위쪽의 동그란 핸들을 끌거나(**Shift**를 누르면 15° 단위) **회전** 슬라이더를 사용합니다. 크기를 바꾸면 이미지 중심을 기준으로 조절됩니다
- **텍스트 · 이미지 · 모자이크** 영역: 설치된 모든 글꼴, 색, 크기의 **텍스트**를 넣고, 어두운 배경 상자(자막 느낌)와 외곽선을 선택할 수 있습니다. 이미지처럼 미리보기에서 옮기고 크기를 바꾸고 돌릴 수 있으며(**Shift**는 15° 단위), 텍스트를 두 번 클릭하면 고칠 수 있습니다. 텍스트 상자에서 **Enter**를 누르면 고른 프레임 아래쪽에 입력한 텍스트가 들어갑니다. 마지막 텍스트 스타일은 기억됩니다
- **자막은 이제 텍스트 항목입니다**: "텍스트 추가"는 기본적으로 아래쪽 가운데에 어두운 배경 상자와 함께 넣어 자막과 같은 모양이지만, 옮기고 크기를 바꾸고 돌리고 스타일을 바꿀 수 있습니다
- **모자이크**: 고른 프레임의 일부를 픽셀화해 개인정보를 가립니다. 끌어서 옮기고, 모서리 핸들로 모양(가로세로 비율 자유)을 바꾸고, 돌릴 수 있으며, **칸 크기** 슬라이더(1–10)로 거칠기를 정합니다. 모자이크는 녹화된 화면만 가리므로 그 위에 올린 텍스트와 이미지는 선명하게 유지됩니다
- 항목(텍스트, 이미지, 모자이크)은 선택한 프레임에 더 표시하거나 제거할 수 있고, 투명도와 각도 슬라이더가 있으며, **Del**로 고른 항목을 삭제합니다
- 항목이 들어간 프레임은 타임라인에 작은 배지(**T** 텍스트, **▣** 이미지, **▦** 모자이크)가 표시되며, 모두 실행 취소할 수 있습니다

**내보내기**
- 용도별 프리셋: **문서용**, **SNS용**(가로 1280px 이하), **게임용**(고화질, 30fps)
- 화질, 이미지 크기, 최대 FPS, 비슷한 프레임 합치기, 반복 횟수(무한 또는 N회)
- **확대 내보내기**: 이미지 크기를 최대 600%까지, ×2 ~ ×6 배율 버튼 또는 슬라이더로 자유롭게. 확대 방식은 **그대로**(선명한 블록), **부드럽게**(바이큐빅), **선명하게**(Lanczos 보간 + 샤프닝, 화면 녹화·글자에 추천), **픽셀아트**(xBR로 도트 그림의 대각선과 곡선을 매끄럽게) 중 선택하며, 미리보기에 결과가 그대로 보입니다
- **예상 파일 크기 실시간 표시**, 목표 용량(예: 15MB)에 **자동으로 맞추기**
- 프레임마다 바뀐 부분만 저장하고, 프레임별 색상표를 실제 쓰는 색 수에 맞춰 줄여 파일이 작습니다
- 빠른 내보내기: 인코딩하는 동안 여러 CPU 코어에서 프레임을 렌더링하며, 저장 중 저장 버튼을 다시 누르면 **취소**됩니다
- 폴더에 바로 저장, 파일을 클립보드에 복사해 메신저에 **Ctrl+V**, 게임 엔진용 **PNG 시퀀스**(표시 시간 CSV 포함) 내보내기
- 기존 GIF를 불러와 편집(버튼, Ctrl+O, 끌어다 놓기)

**업데이트**
- **자동 업데이트 확인**: 시작할 때 GitHub Releases를 확인합니다. 새 버전이 있으면 변경 사항을 보여 주는 창이 열리고, 내려받아 SHA-256을 검증한 뒤 exe를 교체하고 다시 시작할 수 있습니다(폴더에 쓸 수 없으면 릴리스 페이지를 엽니다). **이 버전 건너뛰기**와 **나중에**를 고를 수 있습니다
- **설정 → 업데이트**에서 끌 수 있고, **지금 확인** 버튼도 있습니다

**화면**은 한국어, 영어, 일본어를 지원하며, 가독성을 고려한 고대비 다크 테마입니다. 긴 문구는 칸에 맞춰 줄어들고, 작은 화면에서도 편집기가 들어가도록 사이드바가 스크롤됩니다.

## 시작하기

### 요구 사항
- Windows 10 2004 이상(Windows 11 권장), 64비트

### 빌드와 실행
GIF Capture는 외부 라이브러리 없이 .NET 10 WinForms로 만든 앱입니다.

```powershell
git clone https://github.com/dnwls010728/GIFCapture.git
cd GIFCapture
dotnet run -c Release
```

.NET을 설치하지 않아도 실행되는 단일 `GifCapture.exe`를 만들려면:

```powershell
dotnet publish -c Release -o publish
```

`publish\GifCapture.exe`를 원하는 곳에 복사해 실행하면 됩니다. 설정은 `%AppData%\GifCapture`에 저장됩니다.

## 사용법

### 1. 녹화 대상 고르기
메인 창의 카드 세 개 중 하나를 누릅니다.

- **영역 지정** — 멈춘 화면 위에서 사각형을 드래그
- **창 선택** — 창 위에 마우스를 올리고 클릭
- **전체 화면** — 모니터 클릭

**크기 프리셋**에서 크기를 고르면 그 크기의 영역이 화면 가운데에 바로 만들어집니다.

### 2. 영역 조절하기
영역 둘레에 파란 테두리가 나타납니다. 테두리나 모서리 핸들을 끌면 크기가, 위쪽 크기 탭을 끌면 위치가 바뀝니다.
끄는 동안 돋보기가 가장자리 아래 픽셀을 크게 보여줍니다. 테두리 안쪽은 클릭이 그대로 통과하므로 아래 앱을 계속 쓸 수
있습니다. 메인 창에서 너비와 높이를 숫자로 입력해도 됩니다.

### 3. 녹화하기
빨간 버튼이나 **F9**를 누릅니다. 3초 카운트다운 뒤 테두리가 빨간색으로 바뀌고 경과 시간이 표시됩니다.
다시 **F9**를 누르면 멈춥니다.

녹화 전에 고를 수 있는 것:
- **FPS** — 보통 10–30이면 충분합니다
- **녹화 후** — *편집기 열기*(먼저 확인) 또는 *바로 저장*(마지막 내보내기 설정으로 즉시 저장)
- **마우스 커서**, **클릭 강조**, **키 입력 표시** — 비밀번호를 입력할 때는 *키 입력 표시*를 끄세요

### 4. 편집하기(선택)
편집기가 열리면 모든 프레임이 타임라인에 나옵니다. 클릭, Shift+클릭, 드래그로 프레임을 고른 뒤 **편집** 탭에서
앞뒤 잘라내기, 삭제, 시간 조절, 영역 자르기, 회전을 합니다. 모든 작업은 **Ctrl+Z**로 되돌릴 수 있습니다.

**꾸미기** 탭에서는 모든 프레임에 글자나 이미지 **워터마크**를 넣거나, 고른 프레임에 텍스트(자막 포함)·이미지·모자이크를 넣을 수 있습니다
(버튼, **Enter**, **Ctrl+V**, 또는 이미지 파일을 미리보기로 끌어다 놓기). 미리보기에서 항목이나 워터마크를 끌어 옮기고
모서리 핸들로 크기를 조절하세요.

### 5. 내보내기
**내보내기** 탭에서 용도별 프리셋을 고르거나 화질·크기·FPS를 직접 정합니다. 크기를 100%보다 크게 하면 확대되며
(**×2 ~ ×6** 버튼), **그대로 / 부드럽게 / 선명하게 / 픽셀아트** 중 확대 방식을 고를 수 있습니다. 설정을 바꿀 때마다 예상 크기가 갱신되고,
**목표 용량**을 입력한 뒤 **이 용량에 맞추기**를 누르면 그 용량 안에 들어오는 설정을 찾아줍니다. 파일 이름을 정하고
**GIF 저장**(**Ctrl+S**)을 누르세요. 저장한 파일은 클립보드에도 복사되어 메신저에 바로 붙여넣을 수 있습니다. 저장 중에 버튼을 다시 누르면 취소됩니다.

## 개인정보

GIF Capture는 녹화물이나 어떤 데이터도 업로드·동기화·전송하지 않습니다. 앱이 보내는 네트워크 요청은 GitHub Releases에 새 버전을 확인하는 것뿐이며, 설정 → 업데이트에서 끌 수 있습니다. *키 입력 표시*는 녹화하는
동안에만 키보드 후킹을 사용하며, 누른 키를 내 GIF에 그리는 용도로만 씁니다.
